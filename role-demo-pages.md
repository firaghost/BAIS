## Goal
Create per-role demo pages (HR Admin, Branch Manager, Payroll Officer, Executive Viewer, Employee, etc.) in dedicated folders, and wire them to routing/navigation so the user can provide designs one by one and we can implement them quickly.

## Milestones
1. Decide routing strategy (role-based content vs demo-prefixed routes) and define route map.
2. Scaffold folder structure and route registrations for each role’s demo area.
3. Implement pages iteratively from provided HTML designs, ensuring dynamic data (no hardcoded page data) and consistent layout.
4. Verify navigation and access rules; ensure pages render without console errors.
